## AI Use Declaration

KineticMesh was developed with assistance from AI tools including
ChatGPT, Gemini, and Claude Code.

### AI-assisted work
AI tools were used for:
- Code generation and refactoring assistance
- Debugging and error analysis
- Architecture brainstorming
- Documentation drafting
- UI/UX iteration
- Test-case and validation suggestions

### Human verification
The project author personally:
- Reviewed and integrated generated code
- Tested the core investigation workflow
- Verified environment configuration
- Tested Gemini API integration
- Validated error and unavailable-model states
- Reviewed evidence/verification behavior
- Removed exposed credentials and kept API keys out of source control
- Verified the final demo workflow

AI-generated output was treated as development assistance rather than
as automatically trusted or production-ready code.
